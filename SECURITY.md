# Security Policy

## Supported Versions

Only the 3.x release series receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, use GitHub's private vulnerability reporting (security advisories):

1. Go to the [Security tab](https://github.com/schmittjoh/serializer/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, including affected versions, reproduction steps, and potential impact.

The report stays private until a fix is available and an advisory is published.
